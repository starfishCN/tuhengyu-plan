# 装面板报 ensurepip is not available —— setup.sh 补 python3-venv 兜底

日期：2026-10-03
状态：已修复 / 静态校验通过 / 未推公开仓
关联：`panel/setup.sh`（无版本号，脚本类）

## 现象（朋友机 RainYun 实测，截图）

执行一键安装后：

```
The virtual environment was not created successfully because ensurepip is not
available.  On Debian/Ubuntu systems, you need to install the python3-venv
package using the following command.
    apt install python3.12-venv
Failing command: /opt/tuhengyu-panel/.venv/bin/python3
```

## 根因（已验证）

`setup.sh` 直接 `python3 -m venv .venv`，未处理「最小化镜像不带 `python3-venv`」的情况。这时 `ensurepip` 缺失，`venv` 建不成功，脚本随即中断。

## 修法

`panel/setup.sh` 虚拟环境段改为：先试创建 → 失败则按发行版装 `python3-venv`（apt/dnf/yum）→ 重试；仍失败给出明确提示并退出。

- 版本化包名：`python3.${PYVER#*.}-venv`（由 `python3 -c` 取版本，如 3.12 → `python3.12-venv`）。
- apt 走 `DEBIAN_FRONTEND=noninteractive`，失败逐级兜底并回落到 `python3-venv`。

## 验证

- `bash -n panel/setup.sh` 通过。
- 未在真机重跑（朋友机器不在本终端控制范围）。

## 教程同步

`tutorial/09-常见问题.md` 新增「装面板时报 ensurepip is not available / 建 .venv 失败」条目：给出一条手动命令 `apt-get update -y && apt-get install -y python3-venv`，并说明新版 `setup.sh` 已自带兜底。

- 朋友机的即时解法：先手动 `apt-get install -y python3-venv`，再重跑安装脚本。

# 插件 0.3.8：好感度页签 + 人设驱动的变化曲线（2026-10-02）

## 结论

新增第 5 个页签「好感度」，一次性交付三样：① 每人一行（好感 / 印象 / 关系 / 最近更新），可改可重置可删除；
② 好感**变化曲线参数**由当前人设驱动、LLM 生成并存盘复用（人设指纹不变就不重算）；③ 每人**历史折线图**（原生 Canvas 自绘）。
版本 0.3.7 → 0.3.8。

## 需求与拍板

博士原话：好感度单独一个页签，能根据人设调 LLM 设置好感变化曲线，另能看到每个人的好感、状态、关系等的窗口。
待拍板项答复：「都要」（曲线＝LLM 参数 + 历史折线图，两者都做）、「可改」（页签支持编辑）。未答按默认：
昵称取自会话名，取不到显示 QQ；只列有互动记录的 uid；「叶倩」＝页签。

## 实现

### 数据层 `core/favour.py`

- 新增 `DEFAULT_CURVE`（内置兜底：5 档 bands + 4 类 deltas），把原先写死在 `build_injection` 里的
  `+1~+3 / -3~-10` 升格为「曲线参数」。
- `normalize_curve(raw)`：补全 + 夹逼（band.min 夹 -1000~100，delta 夹 -100~100）。
- `persona_fingerprint(text)`：人设正文 sha1 前 16 位，作「重算判据」。
- `parse_curve_json(text)`：从模型输出抠 JSON，容忍 ``` 围栏。
- `band_of(favour, curve)`：按给定曲线取区间；`build_injection(state, curve)` 新增曲线参数，
  注入文本里的档位描述与四类互动幅度改为按曲线取。
- `FavourStore`：`update()` 增 `name` 与 `updated_at`；新增 `set_state_by_key` / `remove_by_key` / `reset_by_key`
  （页签的键可能形如 `<会话>_<QQ>`，不能只按 QQ 操作）。
- 新增 `HistoryStore`（`favour_history.json`）：好感值**变了才记**、上限 300 条。
- 新增 `CurveStore`（`favour_curve.json`）：`get / set / reset`，落盘复用。

### LLM 层 `core/llm.py`

- 新增 `CURVE_SYSTEM_PROMPT` / `CURVE_PROMPT` / `generate_curve_text()`，与既有 `generate_schedule_text` 同构：
  走 `context.llm_generate`，失败返回空串。

### 注入与回收 `handlers/favour.py`

- `inject_favour`：先 `_ensure_curve()` 拿曲线再注入。
- `_ensure_curve()`：懒加载 + 指纹缓存——人设指纹与盘上一致且来源为 llm 就直接用；否则调一次模型、解析、落盘。
  无人设 / 解析失败 / 生成失败一律**沿用已有曲线**（默认参数兜底），不抛、不阻断对话。
- `collect_favour`：写入昵称（`_sender_name`：`get_sender_name()` → `message_obj.sender.nickname` → 空），
  并在好感变化时记一条历史。

### 路由 `web/routes.py` + `main.py`

- `GET  /astrbot_plugin_tuhengyu/favour-list`   条目 + 每人历史 + 当前曲线
- `POST /astrbot_plugin_tuhengyu/favour-update` 改好感 / 印象 / 关系 / 昵称（`key` + 需改字段）
- `POST /astrbot_plugin_tuhengyu/favour-reset`  `mode=reset` 清零保留 / `mode=delete` 整条移除（连历史）
- `POST /astrbot_plugin_tuhengyu/favour-curve`  `action=regenerate|reset|save`
- `main.py.__init__` 注册上述 4 条；新增实例属性 `_favour_history` / `_favour_curve_store`。

### 前端 `pages/status/`

- `index.html`：第 5 页签「好感度」；面板一＝表格 + 工具条（重算曲线 / 恢复默认曲线 / 刷新）；
  面板二＝曲线信息 + Canvas + 档位 chip + 幅度 chip。
- `app.js`：`loadFavour / renderFavour / favourRow / startEditFavour / saveEditFavour / doFavourReset /
  favourCurveAction / renderCurve / drawFavourChart`。点行选中并重画折线；「编辑」就地变输入框 + 保存/取消。
- `style.css`：页签样式（`.favour-*` / `.band-chip` / `.delta-chip` / `.f-*`）。

## 关键取舍

- **不用任何外链 CDN**：目标机无国际出口，折线图用原生 Canvas 2D 自绘（网格 / 档位虚线 / 折线 / 数据点 / 末点值）。
- **曲线只生成一次**：靠人设指纹缓存，不动人设就不烧 token；「重算曲线」按钮=强制重算。
- **统计三态**：页签里「来源」区分 内置默认 / 由人设生成 / 手动保存。

# 凭据轮换与泄露处置（2026-10-02）

## 事件

0.2.28 文档阶段推送时，误将本地内部交接文档 `README.md`（含两枚明文令牌）覆盖仓库根访客 README，
提交 `697d311` 推到 Gitee；镜像推 GitHub 时被 **Push Protection 拦下**，报错指 `README.md:202` 含 GitHub PAT。

## 处置

1. **撤回暴露内容**：`git show ab01f61:README.md > README.md` 恢复访客版；`git reset --soft ab01f61`，只保留两份工作日志；`--force-with-lease` 推 Gitee → `7f70a91`；本机镜像 `reset --hard origin/main` 后推 GitHub。双端 `main` 均 `7f70a91`。
2. **轮换凭据**（博士提供新值）：
   - 新 GitHub PAT → 本机 `/root/_gitee_clone` 的 `github` remote。
   - 新 Gitee 令牌 → 验证机 `/opt/tuhengyu-panel` 的 `origin` remote；本轮补做本机镜像 `origin` remote。
3. **连通性验证**：三处 remote 均 `git ls-remote HEAD` = `7f70a91`。
4. **内部文档脱敏**：`README.md` 第 201–202 行明文令牌改为「不落明文 + 存放位置」引用，并新增「推送前必检仓库根 README 为访客版」条目。

## 验证

**仓库侧**

- 仓库根 `README.md` 凭据计数：Gitee 侧 0、GitHub 侧 0、本机镜像 0。
- 工作区 `tuhengyu-plan/` 已无明文令牌（仅内部 README 保留脱敏后的前 8 位标识）。

**泄露提交 `697d311` 的匿名可达性**（python3 urllib 探测，2026-10-02）

| 探测 | URL | 结果 | 含义 |
|---|---|---|---|
| 对照·Gitee raw main | `/raw/main/README.md` | 200 | 通道正常 |
| 对照·Gitee raw `ab01f61` | `/raw/ab01f61/README.md` | 200 | 旧提交通道正常 |
| **Gitee raw `697d311`** | `/raw/697d311…/README.md` | **451** | 该对象不再对外提供 |
| 对照·GitHub raw main / `ab01f61` | raw.githubusercontent.com | 200 | 通道正常 |
| **GitHub raw `697d311`** | raw.githubusercontent.com | **404** | 该对象已不可取 |
| Gitee commit 页 | `/commit/697d311…` | 200，全文无 `github_pat_` | 页面不承载明文 |
| GitHub commit 页 | `/commit/697d311…` | 404 | 页面不可取 |

结论（已验证）：**明文不再可匿名读取**。两家平台均已不提供该提交的文件内容。

**凭据本身**

- 旧 Gitee 令牌、旧 GitHub PAT **仍能通过 `git ls-remote`** → **尚未吊销，仍有效**。

## 遗留

- **旧凭据必须在后台正式吊销**（本终端无后台权限，无法代办）。对象虽已不可匿名抓取，但暴露窗口期内已出网，按已泄露处理是唯一确定止损。
- GitHub 侧可在 Security → Secret scanning 确认该 PAT 告警状态。
- 内部 `README.md` 已不落明文；新值仅存于三处 remote 配置内。

## 复用命令

```
# 验令牌（只读，不改动远端）
export GIT_TERMINAL_PROMPT=0
git ls-remote https://<user>:<token>@gitee.com/starfishCN/tuhengyu-plan.git HEAD
git ls-remote https://<token>@github.com/starfishCN/tuhengyu-plan.git HEAD

# 换 remote 凭据
cd /root/_gitee_clone && git remote set-url origin 'https://starfishCN:<TOKEN>@gitee.com/...'
cd /root/_gitee_clone && git remote set-url github 'https://<TOKEN>@github.com/...'

# 改写含密钥的提交
git reset --soft <good-commit> && git add -A && git commit -m ... && git push --force-with-lease
```

## 需求与约束

博士指定第 5 条先做**表情包**，并附加约束：

> 我不想多接 embedding 了

据此定路线：**不做向量检索、不加 embedding / 向量库依赖**。

## 方案（已定案）

**被动附带**：bot 每次回复发出前，按概率在消息末尾附一张表情包。
不主动发消息；库为空时什么都不做。

**选图：目录即标签 + 关键词子串命中 + 随机**，零 token、零 embedding、零配置即可用。

```
assets/stickers/<标签>/xxx.png   → 标签 = 子目录名
assets/stickers/xxx.png          → 标签 = default（散图）
```

优先级：① 文本里出现某标签名 → 该标签随机一张；② default；③ 全部随机；④ 空库 → None。

`context_text` = 此刻作息 `scene + state` + 本条回复正文。

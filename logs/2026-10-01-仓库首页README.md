# 工作日志 · 2026-10-01 · 仓库首页 README

## 本轮目标

给仓库补一个**面向访客的首页 README**（原来的仓库根没有 README，
访客进来只看到一堆 `main.py` / `core/`，不知道这是什么）。

## 核心决策：两份 README，用途分离

| 文件 | 位置 | 面向谁 | 含凭据 |
|---|---|---|---|
| `README.md` | 本地项目目录 | PRTS / 后续接续者 | ✅ 含（不入库） |
| `README-repo.md` → 仓库根 `README.md` | Gitee / GitHub | 仓库访客 | ❌ **不含** |

**本地 README 含验证机凭据**（VPS 地址、root 密码、API key、GitHub/Gitee 令牌），
**绝不能入库**。因此另写一份对外版本，推送时复制为仓库根的 `README.md`。

**维护约定**：以后改仓库首页，改本地 `README-repo.md`，再复制过去。
**不要**把本地 `README.md` 推上去。

## 写作取向

- **面向访客**：先讲「能得到什么」，再讲「怎么装」。不像内部文档那样开门见山讲进度。
- **风险亮明**：单独一节，加粗，不藏在文末小字里。这跟教程的口径一致。
- **不吹功能**：插件明确写「第一版」能做的是发空间，不承诺表情包 / 怼人。
- **反馈要求具体化**：把「报错原文 + `uname -a` / `free -h` / `docker ps`」
  写进 README，减少无效 issue。

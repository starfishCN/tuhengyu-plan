## 二、对官方 install.sh 打的补丁（`vendor/apply_patches.py`）

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| **P1** | 正版 Docker CE 被判为 snap 版，脚本中止 | `docker info \| grep -qi 'snap'` 误匹配 Docker 29.x 的 `io.containerd.snapshotter.v1` | 删掉该宽泛匹配，只保留 `/snap/` 路径判断 |
| **P2** | 镜像已中转载入，③ 仍去 registry 查更新并失败 | `pull_image()` 直接 `docker pull`，不查本地 | pull 前加 `docker image inspect ... \|\|` 短路 |

## 三、关键网络发现（教程必写）

### 目标 VPS 无国际出口

| 类别 | 结果 |
|---|---|
| 国际 | google / pypi.org / registry.npmjs.org / objects.githubusercontent.com **全超时** |
| 国内 | 清华源 / 腾讯云源 / Gitee / npmmirror **全通** |

### 公共 Docker 镜像加速：入口通，blob 不通

- `docker.m.daocloud.io` → 47.100.x（国内），但 blob 走 `image-mirror.r2.daocloud.vip`（**Cloudflare R2**）
- `docker.1ms.run` → 125.72.x（国内），但 blob 走 `cloudfront-docker-cf.mrs.1ms.run`（**Cloudflare**）
- `docker.nju.edu.cn` → 403，不对外提供 Docker Hub 代理
- `docker.xuanyuan.me` / `dockerpull.org` / `dockerhub.icu` / `docker.1panel.*` 等 20 个候选：**全挂**

→ **无国际出口的机器拉不了 Docker Hub 镜像。** 官方脚本的降级链（daemon.json → 1ms → 轩辕）全失败后中止。

### 中转方案（本机实测可行）

```bash
# 有梯子的机器上
skopeo copy --override-os linux --override-arch amd64 \
  docker://motricseven7/snowluma:latest \
  docker-archive:/root/img/sl.tar:motricseven7/snowluma:latest
# 1.9 GB（未压缩）→ gzip -1 → 749 MB
scp sl.tar.gz root@vps:/root/
# VPS 上
gunzip sl.tar.gz && docker load -i sl.tar
```

- 镜像大小：registry 视图 **697 MB**，`docker-archive` 后 **1.9 GB**（layer 未压缩），`gzip -1` 后 **749 MB**。
- 实测速率 0.77 ~ 2.66 MB/s，总耗时约 20 分钟。

**教程前置检查（必须加）**：租机器前确认能否 `docker pull` 一个海外镜像。

## 四、SnowLuma 部署结果

- 容器 `Up`，`Hook pipe connected`，QQ（Electron）进程正常。
- 端口：`5099` WebUI / `6081` noVNC / `3000` OneBot HTTP / `3001` OneBot WS。
- 内存：1.9 GB 机器占用约 756 MB，可用约 1 GB，**偏紧**。
- ⚠️ 未设 `VNC_PASSWD` 时 VNC 无明文密码（走 `/root/.vnc/passwd`）；已在 `.env` 补 `VNC_PASSWD`。
- ⚠️ WebUI 未改密时**每次重建容器都会重新生成 bootstrap 密码**，需从 `docker logs` 取。

## 五、环境事实（复用价值高）

- 目标 VPS 是**非干净机器**：预装宝塔（8889）、nginx（80/888）、MySQL（3306）。
- 官方脚本**检测到宝塔但 Docker 已装时不 die**（只有 Docker 不可用才 die）。
- VPS 上 `setsid nohup ... &` **留不住进程**（SSH 断开即被清理）→ 改用 **systemd service**。
- 面板已 systemd 托管：`/etc/systemd/system/tuhengyu-panel.service`，开机自启。
- 本机（Android + proot Ubuntu 24.04）**装不了 Docker**，但**能装 skopeo**（无需 daemon），可用于拉镜像。

# 面板 pip 无国际出口 —— setup.sh 加国内镜像兜底

日期：2026-10-03
状态：已修复 / bash -n 通过 / 已推公开仓
关联：`panel/setup.sh`

## 现象（朋友机 RainYun 实测，截图）

装面板时 pip 报：

```
WARNING: Retrying (Retry(total=4, ...)) after connection broken by
'NewConnectionError': Failed to establish a new connection:
[Errno 101] Network is unreachable': /simple/pip/
```

## 根因（已验证）

该机器**无国际出口**（PyPI 不可达；与「Docker Hub 拉不动」同因）。`setup.sh` 里 `pip install` 用的是默认源，直连失败即中断。

## 修法

`panel/setup.sh` 依赖安装段改为封装函数 `pip_try()`：先直连 → 失败换清华 TUNA → 再失败换阿里云 → 仍失败给出「手动指定镜像」提示并退出。

- 覆盖 `pip install -U pip` 与 `pip install -r requirements.txt` 两步。
- `requirements.txt` 仅 `nicegui` 一项。

## 教程同步

`tutorial/09-常见问题.md` 新增「装面板时 pip 报 Network is unreachable（Errno 101）」，给出两条手动修复命令 + 全局镜像写法。

## 朋友机即时解法

```bash
/opt/tuhengyu-panel/.venv/bin/pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -U pip
/opt/tuhengyu-panel/.venv/bin/pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r /opt/tuhengyu-panel/requirements.txt
```
然后重跑安装脚本（或用新版 `setup.sh` 自动走镜像）。

## 备注

- 该机器环境障碍成串：先 `python3-venv` 缺（已修）、再 pip 无出口（本修）。后续若继续，镜像/出口相关问题还会复现。
- 未改版本号（脚本类）。

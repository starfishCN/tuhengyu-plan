# 插件 0.3.16 —— 修复戳一戳 OneBot 桥相对导入层级错误

日期：2026-10-02
状态：编码完成 / 静态校验通过 / 已双写部署 / 已重载 / 已验证

## 现象（博士贴的运行日志）

```
[handlers.poke:40]: [图恒宇] 初始化 OneBot 桥失败：
No module named 'data.plugins.astrbot_plugin_tuhengyu.handlers.core'
```

自 15:42 起每约 30 分钟复现一次（16:12 / 16:43 / 17:13 / … / 19:43 连续刷），即每次走到取桥逻辑都失败一次。

## 根因

`handlers/poke.py` 的 `_bridge()` 里写的是：

```python
from .core.onebot import OneBotBridge
```

`poke.py` 位于 `handlers/` 子包内，`.core` 会被解析成 `handlers.core`（不存在），故报 `...handlers.core`。

同一文件顶部其它导入用的是正确的 `..core.*`；此处是 0.3.0 模块化拆分时漏改的一处。

验证：`handlers/` 下唯一一处单点相对导入错误；`grep` 全仓仅此一处 `from .core`（`commands.py` 在插件根，`.core` 是对的）。

## 修法

```diff
- from .core.onebot import OneBotBridge
+ from ..core.onebot import OneBotBridge
```

## 影响面

- 触发点：戳一戳「回戳」路径、以及任何经 `_bridge()` 取 OneBot 桥的功能。
- 因为异常被 `except` 兜住，只 warning 不崩，所以**表现为功能静默失效**：被戳时回戳发不出去。
- 其余功能（发空间、表情包、好感度、群聊）不走这条导入，未受影响——日志里 16:43 `发空间成功` 可佐证。

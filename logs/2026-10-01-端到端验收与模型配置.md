## 三、用户选定的模型：LongCat-2.5-Preview

配置落在 `cmd_config.json`：

```json
"provider_sources": [{
  "provider": "openai",
  "type": "openai_chat_completion",
  "key": ["ak_***"],
  "api_base": "https://api.longcat.chat/openai/v1",
  "timeout": 120
}],
"provider": [{
  "id": "openai/LongCat-2.5-Preview",
  "enable": true,
  "model": "LongCat-2.5-Preview"
}]
```

**直连验证**（`scripts/test_longcat.py`）：

```
base reachable: HTTP 404   （根路径无路由，正常）
对话请求      : STATUS 200  →  key 有效、连通正常
```

### ⚠️ LongCat 是推理模型

原始返回：

```json
"finish_reason": "length",
"message": { "role": "assistant",
             "reasoning_content": "\nThe user is asking me to reply..." },
"usage": { "completion_tokens": 20, "reasoning_tokens": 19 }
```

`max_tokens: 20` 被思考过程吃掉 19 个，`content` 为空。

**风险**：`max_tokens` 配小 → 回复为空 → 看起来像"哑巴"，实为 token 被推理吞光。
**实测结果**：AstrBot 这条路径上**未触发该问题**，正常出字。

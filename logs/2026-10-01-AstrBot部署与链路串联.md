- 同样踩「无国际出口」坑 → 走中转：`skopeo` → `docker-archive`（1.97 GB）→ `gzip -1`（748 MB）→ scp → `docker load`（4.04 GB）。

## 二、容器网络打通

两个容器初始在不同网络（`astrbot` 在 bridge，`snowluma` 在 `snowluma_default`），容器名无法互访。

```
docker network connect snowluma_default astrbot
```

结果：

| 容器 | IP |
|---|---|
| snowluma | 172.18.0.2 |
| astrbot | 172.17.0.2 (bridge) + 172.18.0.3 (snowluma_default) |

→ 两容器现可**用容器名互访**，这是 `ws://astrbot:6199/ws` 能解析的前提。

## 需求

博士两点：

1. WebUI 做 3 个页签（状态 / 操作 / 设置），首页太臃肿；开关按钮也放进去；设置做成下拉式可收起来。
2. 表情包：希望在对话中 bot 会自己收集。

## 需求② —— 对话中收集表情包

`main.py::collect_sticker()`，`@filter.event_message_type(EventMessageType.ALL)`：

- 取 `event.get_messages()` 里的 `Image`，单条最多 2 张；
- `await img.convert_to_file_path()` 归一化取图（URL 自动下载）；
- `save_collected(数据目录/stickers, src, label, max_bytes=5MB)` 存盘；
- 有新存入则 `stickers.reload()`。

`core/stickers.py::save_collected()`：md5 前 16 位命名去重；扩展名不在白名单则存为 `.png`；空文件 / 超 5MB 丢弃。

配置：`sticker.collect_enabled`（默认 true）、`sticker.collect_label`（默认 `collected`）。

## 需求① —— 三页签 + 可折叠设置

页面：

- `index.html` 改为 `nav.tabs`（状态 / 操作 / 设置）+ 三个 `.tab-pane`；
- `app.js` 加 `switchTab()` / `setupTabs()`；设置区 `renderSettings()` 按 `_conf_schema.json` 动态渲染控件，object 分组用原生 `<details>` 折叠；
- `style.css` 加 tabs / tab-pane / set-group / set-field 等样式。

后端（页面直接读写自身配置）：

- `GET /{插件名}/settings` → `{schema, values, options}`；
- `POST /{插件名}/settings` → 收完整值对象，`_merge_settings()` 只合并 schema 声明过的键，`self.config.update()` + `save_config()`，返回 `{ok, values, status}`。

## 踩坑

1. **`Provider` 没有 `provider_id` 属性** → 模型下拉全空。id 必须从 `provider.meta().id` 取（异常时回退 `provider.provider_config["id"]`）。
2. **写入管道会把 HTML 引号实体解码成裸引号** → JS 里用实体写引号会被还原成连续双引号，字符串未闭合、语法报错。改用 `charCode` 数字写法规避。
3. `page_test_moment` 缺 `return json_response(data)`（返回 None），本轮补上。
4. `core/stickers.py` 尾部有一行不可达 `return None`，删掉。

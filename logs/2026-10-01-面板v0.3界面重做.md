## 一、先解决一个前置判断：素材不能用外链

**目标机器无国际出口。** 如果把背景图/字体/图标库用外链引用（CDN、Google Fonts），
在用户的机器上**一律加载不出来** —— 页面只会留一堆破图。

搜索确认可用的开源图标库（均宽松许可、可商用）：

| 图标库 | 许可 | 数量 |
|---|---|---|
| Lucide | ISC | 1500+ |
| Heroicons | MIT | 300+ |
| Tabler Icons | MIT | 5700+ |
| Phosphor | MIT | 9000+ |

**但最终没有下载任何素材。** 理由：

1. **内联 SVG** 比下载的位图更小、更清晰（矢量可缩放）、零外部请求；
2. 位图背景会让面板体积膨胀，且在现代扁平设计里反而显得旧；
3. **许可风险清零** —— 自绘 SVG 不涉及任何第三方权利。

**结论**：装饰用「内联 SVG + CSS 渐变」实现，**不引入任何外部文件**。

同时确认了一个好消息：NiceGUI 3.17.1 的 CSS 与字体**全部从 `/_nicegui/` 本地加载**
（不是 CDN），所以 `ui.icon()` 的 Material 图标离线可用。

## 二、修了一个真 Bug

**`navigator.clipboard` 在 http 下不可用。**

上一版的复制按钮用的是 `navigator.clipboard.writeText()`。但这个 API
**只在安全上下文（HTTPS 或 localhost）才有**。面板是 `http://IP:50505`
—— **非安全上下文，那个按钮点了根本没反应。**

新版改为：

```javascript
if (navigator.clipboard && window.isSecureContext) {
  navigator.clipboard.writeText(text).then(ok).catch(legacy);
} else {
  legacy();   // execCommand('copy') + 临时 textarea
}
```

**这个 bug 在验证阶段完全看不出来**（我无法点击），只有真人在手机上点才会发现。
写在这里提醒：**凡是依赖「安全上下文」的浏览器 API，在 http 面板上都要检查。**

## 三、界面设计

### 主题

深色 + 青紫渐变（`#22d3ee` → `#818cf8`），呼应「图恒宇计划」的科幻感。
右上角有深浅色切换按钮（`ui.dark_mode()`），跟随系统 + 可手动切。

### 布局

```
┌────────────────────────────────────────┐
│ ◉ 图恒宇计划           给 bot 完整的一生 │  ← 品牌栏（SVG logo + 渐变标题）
│   DEPLOY PANEL                     ◐   │
├────────────────────────────────────────┤
│ ┌──── 部署步骤 ────────────────────┐   │  ← 卡片
│ │ ①体检 ②Docker ③SnowLuma ④AstrBot│   │
│ └──────────────────────────────────┘   │
│ ▸ 网络源（测速 / 自动选优）              │  ← 折叠卡片
│ ▸ 找不到密码？点这里读初始凭据            │
│ ┌──── 运行日志 ────────────────────┐   │
│ └──────────────────────────────────┘   │
└────────────────────────────────────────┘
```

### 表格化

凭据改成真表格（自绘 HTML，不用 `ui.table`，因为要嵌复制按钮和完全控制样式）：

| 列 | 说明 |
|---|---|
| 服务 | 名称 |
| 端口 | 等宽字体、灰显 |
| 初始密码 | **等宽粗体**，`word-break: break-all`（手机上长串不会撑破） |
| — | 复制按钮，hover 变青色 |

端口表同样表格化，并把「外网访问要换成你映射的外部端口」做成黄色提示条。

### 手机适配

| 手段 | 效果 |
|---|---|
| `@media (max-width: 640px)` | 断点 |
| `.tg-step { width: 100% }` | 按钮**竖排撑满**，不再是挤成一条 |
| `.tg-hide-sm` | 隐藏副标题等次要信息 |
| 字号/内边距整体缩小 | 表格在窄屏下仍可读 |
| `.tg-wrap { overflow-x: auto }` | 表格过宽时**可横向滑动**（不换行、不挤扁） |

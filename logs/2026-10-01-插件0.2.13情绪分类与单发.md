# 插件 0.2.13 —— 表情包按情绪分类选图 + 单独发/一起发开关

日期：2026-10-01
状态：编码 / 本地校验 / 真机部署 / 接口验证 / 推送 均完成。**浏览器端渲染未验**。

## 起因

博士四项要求：

1. 表情包按情绪分类，**不需要太细分**；
2. 对话时表情单独发还是一起发 —— 给个开关；
3. 表情包发送概率可调；
4. 按 AI 的情绪来选择表情包。

## 做法

### 情绪类目收敛（新建 `core/emotion.py`）

固定 6 类：**开心 / 难过 / 生气 / 惊讶 / 无语 / 害羞**，外加「其他」归置不上的目录。
关键词规则判定（零 token），按类目顺序取先命中者。博士要「不细分」，故就这 6 类，不做自定义、不做层级。

### 选图按 AI 情绪（`StickerLibrary.pick(prefer_emotion=…)`）

1. 先判传入文本的情绪 → 目录同名（`stickers/开心/`）就取一张；
2. 没有则退回原逻辑：标签名子串命中 → `default` 散图 → 全部随机。

配置 `sticker.emotion_match`（默认开）可关掉情绪这一步，退回只看标签名。

### 单独发 / 一起发（新开关 `sticker.send_separate`）

- 关（默认）：表情包跟在 bot 文字回复末尾，**同一条消息**（沿用 `on_decorating_result`）。
- 开：新增 `@filter.after_message_sent()` 钩子（回复已发出后触发），`await event.send(MessageChain([Image.fromBase64(b64)]))` **另发一条只含表情包的消息**。

两条路径靠该开关分流、互斥，不会重复发。概率 `sticker.probability`（默认 0.35）两条路径共用，设置页可调（原本即可调，本轮明确进文档）。

### 页签按情绪归并

`page_stickers` 改用 `groups_by_emotion()`：目录名是情绪名的进对应类目，其余（default / collected / 自定义）归「其他」；item 带 `tag` 标出原始目录名。真机库现全是 `collected` → 归「其他」。

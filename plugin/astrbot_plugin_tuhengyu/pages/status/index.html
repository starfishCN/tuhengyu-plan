操作

换人设后按这个
丢弃盘上已有的作息，重新读当前人设，让模型按新的人设生成一份一天的作息。 人设来自 AstrBot 的「人格」（在「设置」页选，或留空跟随默认）， 改完人设不按这里，作息不会自己变。
立刻发一条 QQ 空间动态（调试用）
等同 QQ 里的 /图恒宇测试：用当前作息生成一条内容并发出去。 会产生真实的空间动态，不要频繁点。
放完表情包后按这个
重新扫描表情包目录。把图放进插件数据目录的 stickers/（子目录名就是标签）后， 按一下即可生效，不必重载插件。对话里收到别人发的图会自动存进 collected/。

表情包库

按分类展示，例：stickers/拒绝/a.png。内置意图类：拒绝 / 道歉 / 攻击 / 亲昵 / 赞同 / 提问 / 认输 / 害羞； 也可在下面新建自定义分类（自定义类名也会作为识图的候选）。散图与对话里收到的图归「其他」。bot 回复时按这条回复的意图，从同名目录里挑图。 把卡片拖到别的分类上即可归类；拖进「其他」＝移回散图区。 拖动只是暂存，改完点「保存归类」才真正写入（一次提交、只刷新一次）。手动归类不调模型、不耗 token。

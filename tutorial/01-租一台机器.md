# 01 · 准备服务器

## 先确认 NAT 和端口映射

如果服务商提供的是 NAT VPS，请先确认它给了端口转发。你至少需要：

| 用途 | 服务器内部端口 | NAT 外部端口 |
|---|---:|---:|
| SSH 登录 | 22 | 服务商分配的 SSH 端口 |
| 部署面板 | 8080 | 你可访问的外部端口 |
| noVNC 远程桌面 | 6081 | 扫码时使用的外部端口 |
| SnowLuma 控制台 | 5099 | 可选，建议限制来源 |
| AstrBot 控制台 | 6185 | 可选，建议限制来源 |
| 容器内部通信 | 6199 | 不要映射到公网 |

NAT 下浏览器访问的是“公网 IP + 外部端口”，不是内部端口。例如服务商把外部 `18080` 转发到内部 `8080`，你要打开：

```text
http://公网IP:18080
```

不要打开 `http://公网IP:8080`。如果没有外部端口映射，面板已经运行也无法从浏览器访问。

## 怎么选

第一次测试建议选择全新的 Ubuntu 22.04 或 24.04 x86_64 云服务器，2 核 4G 起步，磁盘至少 30G。

不要一开始追求最低价。国内线路有时无法拉取 Docker 大镜像，价格低但网络不通的机器会浪费时间。

## 买完后记录四项

- 服务器公网 IP
- SSH 端口
- SSH 用户名，通常是 `root` 或 `ubuntu`
- SSH 密码

密码只保存到密码管理器，不要发到群里。

## 用手机连接

安卓可以使用支持 SSH 的终端应用。填写服务器 IP、端口、用户名和密码，连接后看到类似下面的提示就成功：

```text
root@your-server:~#
```

如果用户名不是 root，后续命令前加 `sudo`，或先切换到 root。

## 先别做这些事

不要先手动安装 git、Python、Docker、pip。新版引导脚本和面板会自动处理这些步骤。

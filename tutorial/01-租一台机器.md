# 01 · 租一台机器

这一篇要做三件事：

1. 挑一台合适的服务器
2. **在掏钱之前，验证它能不能用**（最重要）
3. 拿到登录信息

---

## 一、要什么样的配置

| 项目 | 要求 | 说明 |
|---|---|---|
| 内存 | **4 GB**（最低 2 GB） | 里面要跑一个真实的 QQ 客户端，很吃内存。2 GB 能启动但很紧 |
| CPU | 2 核 | |
| 硬盘 | 40 GB | |
| 系统 | **Ubuntu 22.04 或 24.04** | 别选 CentOS、Debian 也行 |
| 架构 | **x86_64（amd64）** | ⚠️ **别选 ARM**，两个软件的 ARM 版本没验证过 |
| 权限 | **root** | 买的时候留意有没有给 root 密码 |

> ⚠️ **ARM 是常见的坑**：甲骨文免费机、部分低价机是 ARM 架构。
> 买之前确认一下，写着 `x86_64` / `amd64` / `Intel` / `AMD` 的才对。

---

## 二、去哪儿租

常见的：阿里云、腾讯云、华为云、雨云、Vultr、DigitalOcean……

**不用挑最贵的。** 我们要的东西配置要求不高，**关键是网络**。

### 选国内还是国外？

| | 国内服务器 | 国外服务器 |
|---|---|---|
| 下载镜像 | ❌ 常常下不动 | ✅ 飞快 |
| QQ 登录风控 | ✅ 相对安全 | ⚠️ 更容易被风控 |
| 访问速度 | 快 | 慢 |

**建议：国内服务器。** 原因是 QQ 风控是硬伤，而下载问题有解（后面会讲）。

> 如果你已经有国外机器，也可以直接用，就是 QQ 那边风险高些。

---

## 三、⭐ 掏钱前先验证（关键步骤）

**很多便宜的国内服务器，是拉不动 Docker 镜像的。**

这不是配置问题，是网络问题：那些机器的网络**只能连国内**，
连不上国外的软件仓库。

**验证方法：**

### 1. 先买一台**能按小时计费**的

别一上来就买年付。按小时计的机器，验证要几小时就够了，几毛钱的事。

### 2. 连上服务器

买完后，服务商的控制台会给你：

- **IP 地址**（形如 `123.45.67.89`）
- **用户名**（通常是 `root`）
- **密码**
- **SSH 端口**（有些商家不是默认的 22，比如 `53923`）

然后打开你电脑的终端：

- **Windows**：开始菜单搜 `PowerShell`，打开
- **Mac**：打开「终端」

输入（把内容换成你自己的）：

```bash
ssh root@你的IP -p 你的端口
```

第一次会问 `Are you sure you want to continue connecting?`，
输入 `yes` 回车。然后输入密码（**输入时屏幕不显示任何字符，这是正常的**，
输完直接回车）。

看到类似 `root@ubuntu:~#` 的提示符，就是连上了。

### 3. 跑一条命令测试

复制下面这行，粘进去，回车：

```bash
curl -s -o /dev/null -w "%{http_code}" --max-time 15 https://registry-1.docker.io/v2/
```

**看它输出什么：**

| 输出 | 意思 | 怎么办 |
|---|---|---|
| `401` 或 `200` | ✅ **能用**，继续 | 放心往下做 |
| `000` 或卡住不动 | ❌ **连不上 Docker 仓库** | 见下 |
| 长时间没反应 | ❌ 同上 | 见下 |

再测一个：

```bash
curl -s -o /dev/null -w "%{http_code}" --max-time 15 https://gitee.com
```

这个应该是 `200`。如果不是，这台机器的网络可能有问题。

### 4. 如果不通过怎么办

**先别慌，也先别退。**

不通过意味着「不能直接下载」，但**有替代方案**：

- **方案 A**：换一台机器（换个区域试试，比如从北京换到上海）
- **方案 B**：找能按小时计费的、多试几台
- **方案 C**：用有国外网络的机器先下载好，再传过去（复杂，教程后面提）

> **经验**：同一家厂商，不同区域的机器网络情况可能完全不同。
> 别只试一台就下结论。

## 四、端口映射（如果你的机器是 NAT 型）

**先判断你是不是 NAT 型：**

看服务商给你的 IP 和网卡 IP 是否一致。简单点：**看控制台有没有「端口映射」这个功能**。

- **有** → 你是 NAT 型，**必看本节**
- **没有** → 跳过，你有独立公网 IP

### 什么是端口映射

打个比方：你的服务器像一个小区，里面的服务在各自的房间。
NAT 型的机器，外面的人**进不来**，除非你在门卫处登记：
「敲 50505 这个门牌号，就转接到 8080 房间」。

### 你要登记这些

后面会用到这几个「房间号」，**现在先记下来，用到了再回来加**：

| 内部端口 | 外面用什么访问 | 用途 |
|---|---|---|
| 8080 | 你自己定一个（如 50505） | 部署面板 |
| 6081 | 你自己定一个（如 50506） | 远程桌面（扫码登录 QQ 用） |
| 5099 | 你自己定一个（如 50507） | SnowLuma 控制台 |
| 6185 | 你自己定一个（如 43211） | AstrBot 控制台 |

> ⚠️ **别用 22 端口那栏**。SSH 的映射商家一般已经给你配好了。
>
> ⚠️ **内部端口必须填对**。填错了会连接失败，比如把 6081 填成 6018。

**先不用急着配**，到用的时候我会提醒你。

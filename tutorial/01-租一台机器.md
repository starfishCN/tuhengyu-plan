# 01 · 准备服务器

## 怎么选

第一次测试建议选择全新的 Ubuntu 22.04 或 24.04 x86_64 云服务器，2 核 4G 起步，磁盘至少 30G。

不要一开始追求最低价。国内线路有时无法拉取 Docker 大镜像，价格低但网络不通的机器会浪费时间。

## 买完后记录四项

- 服务器公网 IP
- SSH 端口
- SSH 用户名，通常是 `root` 或 `ubuntu`
- SSH 密码

密码只保存到密码管理器，不要发到群里。

## 用手机连接

安卓可以使用支持 SSH 的终端应用。填写服务器 IP、端口、用户名和密码，连接后看到类似下面的提示就成功：

```text
root@your-server:~#
```

如果用户名不是 root，后续命令前加 `sudo`，或先切换到 root。

## 先别做这些事

不要先手动安装 git、Python、Docker、pip。新版引导脚本和面板会自动处理这些步骤。

# 08 · 确认图恒宇插件

新版自动部署会在安装 AstrBot 时预置配套插件，不需要从插件市场下载，也不需要再手动 clone 仓库。

## 一、确认文件

```bash
ls /opt/tuhengyu-panel/data/plugins/astrbot_plugin_tuhengyu
```

如果目录存在，插件文件已就位。

## 二、确认加载

```bash
docker logs astrbot 2>&1 | grep -E 'astrbot_plugin_tuhengyu|生活调度器' | tail -n 20
```

看到插件名称或生活调度器启动记录，说明插件已加载。

## 三、插件做什么

插件提供作息、虚拟行动、空间动态、表情包、好感度、戳一戳和群聊主动插话。具体行为受 AstrBot 人格、插件配置和当前场景影响。

先保持默认参数测试，不要立即提高主动行为概率。QQ 非官方接口对主动行为更敏感。

## 四、插件未加载

1. 确认目录存在。
2. 执行 `docker restart astrbot`。
3. 查看最近 80 行日志。
4. 若仍失败，复制完整错误，不要只发“插件没反应”。

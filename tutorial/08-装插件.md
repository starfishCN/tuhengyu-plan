# 08 · 装插件：让它会自己发空间

到这一步，你的机器人会聊天了。但它是**被动的** —— 你不说话，它就沉默。

现在装插件，给它「一生」：**作息、主动行动、发空间动态**。

---

## 一、为什么不能一键装

AstrBot 有一个「插件市场」，点一下就能装。

⚠️ **但它在国内机器上用不了** —— 插件市场要访问国外的服务，会被挡住。

所以**只能手动装**。不复杂，就是几条命令。

---

## 二、拿到插件

插件代码在项目的仓库里：

```
https://gitee.com/starfishCN/tuhengyu-plan
```

打开后，在 `plugin/` 目录下能看到 `astrbot_plugin_tuhengyu` 这个文件夹。

### 把它下载到服务器上

连上服务器，执行（两行，逐行来）：

```bash
cd /tmp
git clone --depth 1 https://gitee.com/starfishCN/tuhengyu-plan.git
```

> 没有 `git` 的话，先装：`apt update && apt install -y git`

克隆下来后，插件就在 `/tmp/tuhengyu-plan/plugin/astrbot_plugin_tuhengyu`。

---

## 三、放到 AstrBot 的插件目录

AstrBot 装在 Docker 容器里，它的插件目录在宿主机上的位置是：

```
/opt/tuhengyu-panel/data/plugins/
```

> 这个路径是面板预设的。如果你的不一样，用下面的命令确认：
>
> ```bash
> docker inspect astrbot --format '{{range .Mounts}}{{.Source}} -> {{.Destination}}{{"\n"}}{{end}}'
> ```
>
> 找到映射到 `/AstrBot/data` 的那个宿主机路径，插件的目录就是它下面的 `plugins/`。

复制过去：

```bash
cp -r /tmp/tuhengyu-plan/plugin/astrbot_plugin_tuhengyu \
      /opt/tuhengyu-panel/data/plugins/
```

---

## 四、重启 AstrBot

```bash
docker restart astrbot
```

**等 10 秒左右**，然后看日志：

```bash
docker logs astrbot 2>&1 | tail -40
```

**看到这两行就是成功了：**

```
Loading plugin astrbot_plugin_tuhengyu ...
Plugin astrbot_plugin_tuhengyu (0.2.0) by starfishCN
[图恒宇] 生活调度器已启动。
```

> `生活调度器已启动` 是关键 —— 说明插件的心跳跑起来了。

### 顺便确认链路自动接回

重启 AstrBot 后，SnowLuma 会自动重连（因为配了重连间隔）。
等半分钟，看 AstrBot 日志里有没有：

```
aiocqhttp(OneBot v11) 适配器已连接。
```

有就对了。

---

## 五、先手动测一次

插件装好了，但它自己发空间是**按概率的**（默认 15%，而且间隔至少 6 小时）。
**等它自己发可能要很久** —— 所以我们先手动触发一次。

用**另一个 QQ** 给机器人发：

```
/图恒宇测试
```

> ⚠️ **斜杠不能省。** AstrBot 默认用 `/` 作为命令前缀。

### 应该发生什么

```
你：  /图恒宇测试
机器人：[图恒宇] 正在生成并发布，稍等 ...
机器人：[图恒宇] 已发布：刚下班路上看到天边一片橘红色的晚霞，
       好看得站在原地看了好一会儿，突然觉得今天也没那么累了
```

**然后去机器人的 QQ 空间看一眼 —— 这条动态应该真的发出去了。**

### ✅ 到这一步，插件就活了

之后它会：

- 在设定的作息时间内（默认 09:00–23:00）
- 每隔一段时间（默认 30 分钟检查一次）
- 有 15% 的概率
- 自己发一条动态

## 六、关于人设：交给你

插件**不预设任何角色**。

它默认用一个很普通的、平和的语气写动态。**这是故意的** ——
因为「你的 bot 是什么性格」应该由你自己决定。

### 怎么改

在 AstrBot 的插件配置页里（或者插件的配置文件里），找到：

| 配置项 | 作用 | 默认 |
|---|---|---|
| `persona_prompt` | **人设提示词** | 空（用内置通用口吻） |
| `moment_prompt` | 发说说的指令 | 空（用内置默认） |
| `active_hours` | 作息时间 | `09:00-23:00` |
| `act_probability` | 每次检查的行动概率 | `0.15` |
| `moment_min_interval_hours` | 两条动态最短间隔 | `6` |
| `check_interval_minutes` | 多久检查一次 | `30` |
| `llm_provider_id` | 用哪个模型 | 空（用默认） |

### 人设提示词怎么写

`persona_prompt` 里填一段描述。例子：

```
你是「小夜」，一个话不多的夜班便利店店员。
习惯凌晨活跃，喜欢在没人时写点东西。
说话短，不用感叹号，偶尔会提到今晚的天气。
```

**写得越具体，动态越像「一个人」写的，而不是「一个 AI」写的。**

具体怎么调人设，见 [10 · 然后呢](10-然后呢.md)。

---

## 七、⚠️ 风险提醒

再强调一次，因为这一步之后它就开始**自己动手**了：

1. **主动行为是高危区。** QQ 对「自己发动态的号」比「被动回复的号」更敏感。
2. **保持克制。** 默认参数已经压得很低了，**别为了看着热闹去调高**。
3. **先用小号跑一段时间。** 确认稳定了再说。
4. **出事了别怪工具。** 这是非官方接口，风险自担。

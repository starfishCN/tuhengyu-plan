# 00 · 先读这个

这套项目的目标：在你自己的服务器上运行一个 QQ 机器人。

你只需要完成三件事：

1. 准备一台服务器并用 SSH 登录。
2. 复制一段引导命令，打开部署面板。
3. 登录面板后按顺序点击「1. 部署必要软件」和「2. 扫码后完成设置」。
4. 第一步完成后，在面板凭据区域输入 noVNC 外部端口并点击「打开 noVNC」扫码登录 QQ；第二步输入当前 AstrBot 密码。

后面的模型配置和机器人测试，按 07、09 篇执行。

## 你会得到什么

- SnowLuma：运行 QQ 客户端并提供 OneBot 通信。
- AstrBot：处理消息、调用模型。
- 图恒宇插件：提供作息、空间、表情包、好感度、戳一戳和群聊行为。
- 部署面板：把安装和排错集中在一个网页里。

## 需要准备

| 项目 | 建议 |
|---|---|
| 系统 | Ubuntu 22.04 / 24.04 |
| 架构 | x86_64 |
| 配置 | 至少 2 核 4G，磁盘至少 30G |
| 账号 | 建议使用 QQ 小号 |
| 网络 | 能访问至少一个国内软件源或项目下载源 |

## 必须知道

- QQ 非官方接口存在封号和限制风险。
- 不要使用主 QQ 号。
- 不要把 SSH 密码、API Key、Token 发给别人或提交到仓库。
- 面板、AstrBot、SnowLuma 都是管理入口，长期使用时不要把不必要的端口暴露到公网。

## 遇到问题

不要连续重复点击。打开面板日志，复制最后 20 行。常见网络和安装问题见 [09 · 常见问题](09-常见问题.md)。

# 00 · 先读这个

**五分钟，读完再动手。** 这里没有技术内容，只有「你要准备什么、要花多少、会踩什么坑」。

---

## 你需要准备什么

| 东西 | 说明 |
|---|---|
| 一台电脑 | Windows / Mac 都行。只用浏览器，不用装软件 |
| 一部手机 | 装 QQ，用来扫码登录 |
| 一个 **QQ 小号** | 别用主号，理由见下 |
| 几块到几十块钱 | 服务器 + 模型 API |
| 半小时左右 | 第一次做会慢些 |

---

## 要花多少钱

| 项目 | 大约费用 | 说明 |
|---|---|---|
| 云服务器（VPS） | **30～60 元/月** | 配置要求见下一篇 |
| 模型 API | **几块钱起** | 按用量计费，发说说这种量很省 |

**没有其他费用。** 教程里的软件全部免费。

> 小技巧：很多云厂商有按小时计费的机器，**验证阶段用几小时就够了**，
> 几毛钱成本。跑通了再决定要不要长期租。

---

## 要花多久

熟练的话 **20 分钟**。第一次做，算上注册账号、等服务器开机、排错，
**留出一小时**比较稳妥。

主要时间花在两个地方：

1. **拉 Docker 镜像**（要几分钟，甚至十几分钟，取决于你的网络）
2. **扫码登录 QQ**

---

## ⚠️ 最大的坑：你的服务器可能拉不动镜像

**这一条会决定你后面顺不顺，请务必看。**

我们需要从网上下载两个软件（SnowLuma 和 AstrBot 的镜像）。
下载源在**国外**。

- 如果你租的是**国外服务器**（香港、日本、美国等）→ 下载飞快
- 如果你租的是**国内服务器** → **可能完全下不动**

而国内服务器反过来有个好处：**QQ 登录更不容易被风控**。

这是个两难。**国内服务器 + 解决下载问题**是最优解，
教程第 01 篇会教你怎么**在掏钱前就验证**这一点。

> 一句话：**别急着买年付。先买一台能按小时计的，验证通不通再说。**

---

## ⚠️ 第二个坑：非官方接口有封号风险

我们用的方法，**QQ 官方不允许**。

可能发生的：登录失败、需要重新扫码、严重的话账号被限制。

**所以：**

- **别用主号。** 去注册个新 QQ，或者用小号
- **别发太勤。** 教程默认「最短间隔 6 小时 + 每次 15% 概率」，
  这个频率是故意压低的，别调高
- **别加太多陌生人。** 新号到处加人容易触发风控

> 教程的默认参数是**保守**的。想更活跃，先跑稳一段时间再慢慢试。

## 术语表（看不懂先跳过）

做的时候遇到这些词，回来查：

| 词 | 说人话 |
|---|---|
| **VPS / 云服务器** | 一台放在机房里、你通过网络远程操作的电脑 |
| **SSH** | 远程操作那台电脑的方式，表现为一个黑框框 |
| **Docker** | 一个「软件集装箱」。把软件和它需要的一切打包，一装就是一整套，不用配环境 |
| **镜像（image）** | Docker 用的软件包。要从网上下载 |
| **端口 / 端口映射** | 网络上的「门牌号」。服务器上的服务要通过某个门牌号才能被外面访问 |
| **反向 WebSocket** | 一种通信方式。这里指两个软件互相连起来 |
| **面板** | 我们做的一个网页工具，点点按钮帮你装东西 |

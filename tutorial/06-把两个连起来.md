# 06 · 确认通信链路

自动部署负责安装组件、预置插件，并自动写入 SnowLuma 的 OneBot WebSocket 客户端。AstrBot 的 OneBot 反向 WebSocket 服务端仍需在 AstrBot 控制台创建一次。通信是否建立，要以两个容器的日志和控制台状态为准。

## 一、先看状态

```bash
docker ps --format '{{.Names}} {{.Status}}'
docker logs --tail 80 astrbot
docker logs --tail 80 snowluma
```

如果控制台显示 QQ 在线、OneBot 已连接，直接进入 07。

## 二、若显示未连接

确认两个容器在同一 Docker 网络：

```bash
docker inspect -f '{{json .NetworkSettings.Networks}}' astrbot
docker inspect -f '{{json .NetworkSettings.Networks}}' snowluma
```

如果不在同一网络，先查看网络名：

```bash
docker network ls
```

再把 AstrBot 接入 SnowLuma 所在网络：

```bash
docker network connect 网络名 astrbot
```

具体连接参数以当前 AstrBot 和 SnowLuma 版本的控制台为准，不要盲目照抄旧版配置。常见参数是：

```text
地址：ws://astrbot:6199/ws
端口：6199
Token：两边填写同一串自定义值
```

6199 是内部通信端口，禁止映射到公网。

## 三、验收

- SnowLuma 控制台显示 OneBot 已连接。
- AstrBot 控制台显示 QQ 在线或适配器已连接。
- 两边日志出现连接时间接近的成功记录。

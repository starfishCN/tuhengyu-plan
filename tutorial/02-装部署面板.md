# 02 · 装部署面板

这一篇只有一步：**在服务器上跑一条命令。**

---

## 一、先装两个小工具

面板需要 `git` 和 `python3`。

- **python3**：Ubuntu 22.04 / 24.04 自带，不用管
- **git**：可能没有，先装上

连上服务器（见 01 篇），执行：

```bash
apt update && apt install -y git
```

> 如果提示 `E: Unable to locate package`，先执行 `apt update` 再试。

---

## 二、跑一键安装命令

**复制下面这整行**，粘进终端，回车：

```bash
curl -fsSL https://gitee.com/starfishCN/tuhengyu-plan/raw/main/install.sh | bash
```

### 它会做什么

```
1. 检查你是不是 root（不是就报错退出）
2. 从 Gitee 拉取源码到 /opt/tuhengyu-panel
   （Gitee 拉不动会自动试 GitHub）
3. 建一个独立的 Python 运行环境
4. 装依赖
```

**不需要你做任何选择，它会自己跑完。**

### 成功的样子

最后会输出：

```
[图恒宇] 安装完成。启动：/opt/tuhengyu-panel/.venv/bin/python /opt/tuhengyu-panel/main.py
```

**看到这行就是装好了。**

### 如果卡在「拉取源码」

说明 Git 连不上 Gitee。

```bash
curl -s -o /dev/null -w "%{http_code}" --max-time 10 https://gitee.com
```

应该返回 `200`。如果返回 `000`，这台机器的网络有问题。

---

## 三、启动面板

**注意：安装脚本不会自动启动面板。** 要手动启一次。

### 先临时跑起来验证

```bash
cd /opt/tuhengyu-panel
nohup ./.venv/bin/python main.py > panel.log 2>&1 &
```

等几秒，然后：

```bash
tail -20 panel.log
```

看到类似 `Uvicorn running on http://0.0.0.0:8080` 就是起来了。

### 浏览器访问

```
http://你的IP:8080
```

> 如果你在 01 篇配了端口映射，用的是**外部端口**（比如 50505）。

**弹出一个登录框，就说明面板活了。**

| 用户名 | `admin` |
|---|---|
| 密码 | `Tuhengyu2026` |

---

## 四、启动面板

**新版安装脚本已经自动装好并启动了服务。** 先确认一下：

```bash
systemctl status tuhengyu-panel
```

- **看到绿色的 `active (running)`** → 已经跑起来了，直接跳到第五节
- **提示 `Unit tuhengyu-panel.service could not be found`** → 手动装（见下）

### 手动装服务（旧版脚本或异常时）

**仓库里带了一个现成的 service 文件，复制过去就行：**

```bash
cp /opt/tuhengyu-panel/deploy/tuhengyu-panel.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now tuhengyu-panel
```

> ⚠️ **不要自己手写这个 service 文件。**
>
> 面板的登录认证靠 `PANEL_USER` / `PANEL_PASS` 两个**环境变量**传入，
> 它们写在 service 文件里。手写时很容易漏掉这两行 ——
> **漏了面板就不会弹登录框**（等于无密码运行），而它能执行任意系统命令。
>
> **如果确实要手写**，务必带上这两行：
>
> ```ini
> [Service]
> Environment=PANEL_USER=admin
> Environment=PANEL_PASS=你的密码
> ```

### 想改面板密码

编辑 `/etc/systemd/system/tuhengyu-panel.service` 里的 `PANEL_PASS`，然后：

```bash
systemctl daemon-reload
systemctl restart tuhengyu-panel
```

### 面板密码没设会怎样

**不会裸奔。** 面板启动时会自己检查：

- 环境变量里有 `PANEL_PASS` → 用它
- 没有 → **自动生成一个随机密码**，写进安装目录下的 `.panel_pass`
  文件（权限 600），并**在启动日志里打印出来**

看日志里自动生成的那个：

```bash
journalctl -u tuhengyu-panel | grep 图恒宇
```

或者直接看文件：

```bash
cat /opt/tuhengyu-panel/.panel_pass
```

### 以后常用命令

```bash
systemctl status tuhengyu-panel    # 看状态
systemctl restart tuhengyu-panel   # 重启
journalctl -u tuhengyu-panel -f    # 看日志（Ctrl+C 退出）
```

## 五、⚠️ 安全提醒

面板能执行系统命令（它要装 Docker），**等于一台机器的遥控器**。

**现在它裸在公网上，密码还是默认的。**

- 验证阶段可以先将就
- **跑通后第一件事就是改密码**（见 [10 · 然后呢](10-然后呢.md)）
- 或者只允许你自己的 IP 访问（云厂商控制台的安全组里设）

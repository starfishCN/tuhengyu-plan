# 05 · 确认 AstrBot

AstrBot 已由「开始自动部署」安装。此篇只做确认和登录，不再单独点击旧版安装按钮。

## 一、读取凭据

面板首页展开凭据区域，点击「读取 / 刷新」。记录 AstrBot 控制台地址、用户名和初始密码。

默认内部端口是 `6185`。使用公网端口映射时，访问你设置的外部端口。

## 二、登录并改密码

浏览器打开 AstrBot 地址，使用初始凭据登录。进入后立即修改密码并保存。

如果面板读取不到初始密码，可在服务器执行：

```bash
docker logs astrbot 2>&1 | grep 'Initial password' | tail -n 1
```

## 三、确认容器

```bash
docker ps --format '{{.Names}} {{.Status}}'
```

应能看到 `astrbot` 和 `snowluma`。容器不在运行时，回到面板高级模式单独重试对应步骤。

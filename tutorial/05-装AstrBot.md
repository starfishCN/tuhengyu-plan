# 05 · 装 AstrBot

SnowLuma 是「手和嘴」，现在装「大脑」。

---

## 一、④ 安装 AstrBot

回到面板，点 **「④ 安装 AstrBot」**。

这个快得多（几分钟内）。装完后，日志里会有容器启动的信息。

### 它开了什么端口

| 内部端口 | 用途 |
|---|---|
| **6185** | AstrBot 的网页控制台 |
| **6199** | 给 SnowLuma 连接用的接口（**先不用管，第 06 篇用**） |

---

## 二、配端口映射（NAT 型机器）

去服务商控制台加两条：

| 内部端口 | 外部端口（自己定） | 用途 |
|---|---|---|
| **6185** | 例：`43211` | AstrBot 控制台 |
| **6199** | **不要映射出去！** | 容器之间内部用 |

> ⚠️ **6199 千万别映射到公网。** 它是内部通信口，
> 暴露出去等于把你机器人的「神经」露在外面。
>
> 如果你用的是**独立公网 IP** 的机器，也不需要管 6199 ——
> 两个容器在服务器内部自己就能通。

---

## 三、找到登录密码

**面板能直接读出来。**

回到面板，展开 **「找不到密码？点这里读初始凭据」**，
点 **「读取 / 刷新」**，AstrBot 那一行就是。

### 手动查

```bash
docker logs astrbot 2>&1 | grep 'Initial password' | tail -n 1
```

输出形如：

```
➜  Initial password: Nrvn5CCJ9P9rAR3ghsgDbg1b
```

> ⚠️ **这行只在第一次启动时打印。** 如果命令没输出，说明容器不是全新的了。
> 这时候用面板读（它在日志里翻），或者把数据目录清掉重装。

**抄下来。**

---

## 四、打开控制台

浏览器访问：

```
http://你的IP:43211
```

用刚拿到的用户名密码登录。

登进去后，你会看到一个后台界面 —— 这就是**大脑的驾驶舱**。

**先别急着点。** 界面里的东西都是英文或术语，我们先做一件事，再慢慢填。

---

## 五、⚠️ 马上改密码

**这台的密码是随机生成的，但控制台暴露在公网 —— 必须改掉。**

在 AstrBot 控制台里找到：

```
设置 / 修改密码
```

（不同版本位置不同，一般在右上角用户菜单里，或者「配置」页里。）

改成你自己记得住的密码。**改完记下来。**

---

## 六、现在是什么状态

| 组件 | 状态 |
|---|---|
| SnowLuma | ✅ 运行中，QQ 已登录 |
| AstrBot | ✅ 运行中，能登录控制台 |
| 两者之间 | ❌ **还没连上** |

控制台首页现在应该是「未连接 / 离线」的状态，**这是正常的**。

下一篇，我们把它们接上。

| 检查项 | 应该看到 |
|---|---|

| 控制台能打开 | ✅ 用日志里的密码能登进去 |
| 密码已改 | ✅ 用自己的密码能登 |
| 6199 | **没有**映射到公网 |

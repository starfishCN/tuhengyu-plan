# 图恒宇计划 · 教程

这套教程按当前版本编写。普通用户只需要执行一条引导命令，再在面板点击一次「开始自动部署」。

| 篇 | 内容 |
|---|---|
| 00 | 开始前确认配置、风险和目标 |
| 01 | 准备服务器并连接 SSH |
| 02 | 用多源引导命令安装面板 |
| 03 | 在面板一键部署全部组件 |
| 04 | 通过 noVNC 登录 QQ |
| 05 | 确认 AstrBot 和初始凭据 |
| 06 | 确认 SnowLuma 与 AstrBot 通信 |
| 07 | 配置模型并发送第一条测试消息 |
| 08 | 确认配套插件已预置并加载 |
| 09 | 按现象排错 |
| 10 | 人设、安全、备份和长期运行 |

高级按钮、Docker、镜像源和容器细节只在排错时阅读。

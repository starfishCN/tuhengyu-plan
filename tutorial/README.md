# 图恒宇计划 · 教程

**给 bot 完整的一生。**

这是一套面向**零基础**的教程。你不需要懂编程、不需要会用 Linux，
只要肯照着做，先运行一条命令，再在面板点击一次「开始自动部署」。

---

## 你会得到什么

一个**属于你自己的 QQ 机器人**。它：

- 用**你自己的 QQ 号**登录（不是小号池，不会被别人共用）
- 接**你自己的模型**（国内 API 就行，不用翻墙）
- 有**作息**——什么时候活跃、什么时候安静
- 会**自己发空间动态**（内容由模型生成，不是复读）
- 以后还能长（发表情包、主动说话、怼人，都在路上）

整个系统跑在**你自己租的一台云服务器**上，数据都在你手里。

---

## 系统长什么样

```
QQ ←→ SnowLuma ←(OneBot v11)→ AstrBot ←→ 模型 / 插件
     （登录QQ）   （通信协议）   （大脑）      （性格）
```

三样东西，缺一不可：

| 组件 | 作用 | 打个比方 |
|---|---|---|
| **SnowLuma** | 让 QQ 号登录并收发消息 | 手和嘴 |
| **AstrBot** | 决定回什么、怎么回 | 大脑 |
| **插件** | 让它有生活、有作息 | 灵魂 |

部署面板会帮你把前两样装好。插件在最后一步装。

## 两个提前警告

**一、这东西用的是非官方接口。**

QQ 官方不允许这种行为。用它意味着**有被封号的风险**。所以：

- **不要用你的主号**，注册个新号（或小号）
- 不要发得太频繁（教程里的默认参数已经很克制了）
- 出事了别怪教程

**二、你的服务器会暴露在公网上。**

教程里会反复提醒你**改密码**、**别乱开端口**。验证阶段图方便可以放松一点，
正式长期用的话，该做的安全措施要补上。

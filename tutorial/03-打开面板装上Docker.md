# 03 · 一键自动部署

新用户只使用面板首页的「开始自动部署」按钮。

## 操作

1. 登录面板。
2. 确认当前页面显示「新手入口」。
3. 点击「开始自动部署」。
4. 等待日志出现「一键自动部署完成」。

部署过程会按顺序完成：

1. 环境体检
2. 安装 Docker
3. 自动测速并应用可用镜像源
4. 安装 AstrBot
5. 安装 SnowLuma
6. 装配套插件

不要重复点击，也不要同时打开高级模式。高级模式只用于排错。

## 失败时怎么办

只看日志最后一条带 `!!` 的内容。自动流程会在失败处停止，不会继续执行后面的步骤。

- 没有可用镜像源：换服务器线路，或准备代理、镜像中转。
- Docker 安装失败：复制最后 20 行日志。
- AstrBot 镜像失败：先重新执行一次；仍失败则按 09 篇处理。
- 页面提示任务执行中：等待当前任务结束。

## 完成后的状态

「自动部署完成」表示组件已安装并启动。接下来还需要登录 QQ、确认通信状态、配置模型。不要把它理解成机器人已经可以聊天。

# 03 · 打开面板，装上 Docker

这一篇做四件事：打开面板 → 环境体检 → 配网络源 → 装 Docker。

---

## 一、打开面板

浏览器访问：

```
http://你的IP:50505
```

> 端口 `50505` 是举例。如果你在 01 篇映射了别的端口，换成你自己的。

会弹出登录框：

| 用户名 | `admin` |
|---|---|
| 密码 | `Tuhengyu2026` |

> ⚠️ 这个密码是**固定的默认密码**（写在安装脚本里）。等全部装完后，
> 建议改掉，别让它一直裸在公网上。

登进去后，看到一排按钮：

```
① 环境体检   ② 安装 Docker   ③ 安装 SnowLuma   ④ 安装 AstrBot   ⑤ 连线（待实现）
```

下面还有一个「网络源」的折叠区，和一个黑色的日志窗口。

**⚠️ 日志窗口是重点。** 你点的每个按钮，做了什么、成功还是失败，
全在那里面滚动显示。**出错时，先看它。**

---

## 二、① 环境体检

点 **「① 环境体检」**。

它会检查：系统版本、内存、磁盘、网络连通性等等。

**看日志窗口**，等它跑完（右上角会有提示：完成 / 失败）。

**体检不通过怎么办：**

| 提示 | 含义 | 怎么办 |
|---|---|---|
| 内存不足 | 少于 2 GB | 换机器。2 GB 是死线 |
| 架构是 aarch64 | ARM 机器 | **换机器**。我们没验证过 ARM |
| 磁盘不足 | 少于 20 GB | 换机器 |
| 系统不是 Ubuntu | | 22.04 / 24.04 最稳，Debian 也能试 |

> 体检是「体检」，**不通过不会阻止你继续**。但硬性条件不够的话，
> 后面一定会在某个地方炸掉。**宁可现在换机器。**

---

## 三、网络源：先测速

**展开「网络源（测速 / 自动选优）」这个折叠区。**

它的作用是：**给 Docker 换一个国内能连上的下载源**。

还记得 00 篇说的「国内服务器可能拉不动镜像」吗？
这一节就是解决它 —— 换个国内镜像源，就能拉了。

### 操作

1. 点 **「一键测速并自动选优」**
2. 等它跑完（会并发测试好几个候选源）
3. 它会**自动选中最快的那个**

日志里会列出各个源的延迟。选中的那个会打上标记。

4. 点 **「应用选中的镜像加速（写 daemon.json 并重启 Docker）」**

> ⚠️ **此时 Docker 还没装**，应用会报错 —— **这是正常的。**
> 顺序应该是：**先装 Docker（下一步）→ 再回来配源**。
>
> 或者你也可以：装完 Docker 后回到这里，重新测速、应用。

**记住这个折叠区在哪**，等下要用。

---

## 四、② 安装 Docker

点 **「② 安装 Docker」**。

**这一步比较久，可能几分钟。** 盯着日志窗口，会一行行往下滚。

看到类似这样的收尾，就是成功了：

```
Docker version 27.x.x, build xxxxx
```

### 验证

日志里应该有一行输出 `docker version` 的结果。看到版本号就对了。

### 如果失败

**最常见的原因：Docker 安装源连不上。**

解决：

1. 如果日志里有「换源」相关的提示，说明脚本已经在尝试了
2. 回到上面的 **「网络源」** 折叠区，重新测速、应用
3. 再点一次 ②

> 脚本本身已经内置了「换清华源」等处理（针对国内环境优化过）。
> 如果还是失败，把日志**完整**贴出来搜。

---

## 五、装完 Docker 再配一次源

现在 Docker 在跑了，**回到「网络源」折叠区**：

1. 重新点 **「一键测速并自动选优」**
2. 点 **「应用选中的镜像加速」**

这次应该会成功，日志里能看到它写了配置并重启了 Docker。

**这一步做完，后面拉镜像就不会卡死了。**

---

## 完成检查

| 检查项 | 应该看到 |
|---|---|
| 面板能打开 | ✅ |
| 环境体检 | 无致命问题（内存 ≥ 2G、x86_64） |
| Docker | 日志里有版本号 |
| 镜像加速 | 已应用，无报错 |

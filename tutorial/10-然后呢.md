## 一、给它一个性格

现在你的 bot 说话像客服：礼貌、平淡、没有个性。

**但它本来可以是任何人。**

### 两个层次的人设

| 层次 | 管什么 | 在哪儿配 |
|---|---|---|
| **AI 对话人设** | 它**聊天时**是什么样 | AstrBot 的「人格 / Persona」设置 |
| **插件人设** | 它**发动态时**是什么样 | 插件的 `persona_prompt` |

**建议两边写成同一个人。** 不然会出现「聊天时温柔、发动态时像个营销号」的割裂感。

### 怎么写好人设

**① 少用形容词，多用行为。**

| ❌ 不好 | ✅ 好 |
|---|---|
| 性格温柔、很可爱 | 说话短，句尾常带「呢」；别人说难过的事，它会先问「吃了吗」 |
| 是个高冷的人 | 别人问三句它答一句，回答不超过 10 个字 |

**② 给具体的例子。**

不要写「说话很幽默」，写：

```
别人说「今天好累」，它的回答：
「累就对了。说明你还活着。……要不要听点没用的？」
```

**③ 定义它不做什么。**

```
- 不用感叹号
- 不发「哈哈哈」
- 别人夸它，它会说「哦」，不说「谢谢」
```

**④ 越具体越像人。**

「25 岁，在便利店上夜班，养了一只不爱理人的猫，喜欢在凌晨写东西」——
比「一个温柔的人」强一百倍。

### 直接抄的模板

```
你是「」，岁。

【你是什么人】
（一句话。比如：在便利店上夜班的店员 / 退役的拳击手 / 一个总是迷路的旅人）

【你怎么说话】
- 句子长度：
- 标点习惯：
- 口癖：

【你的生活】
（越具体越好。有什么习惯？几点醒？讨厌什么？）

【别人 xxx 的时候，你会说】
（给 2～3 个例子）

【你不做的事】
- 
- 
```

**填满这张表，bot 就活了。**

## 二、调整生活节奏

插件默认很克制。你可以按需要调：

| 参数 | 默认 | 调大 / 调小的效果 |
|---|---|---|
| `active_hours` | `09:00-23:00` | 想让它是夜猫子，改成 `20:00-04:00`（支持跨午夜，也支持多段：`08:00-12:00,18:00-23:00`） |
| `act_probability` | `0.15` | 调大→更活跃（**也更危险**） |
| `moment_min_interval_hours` | `6` | 调小→发得更勤 |
| `check_interval_minutes` | `30` | 检查频率。调小→反应更及时，也更费 |

> ⚠️ **调快之前想清楚。** 一个每天发十条动态的号，一眼就是机器人。
> **真实的人不会那么勤快。**

## 三、还能加什么

插件目前是**第一版**。后面可以长：

| 功能 | 想法 |
|---|---|
| **发表情包** | 让它能发图，而不只是文字 |
| **主动说话** | 不是等人问，而且自己找话题 |
| **怼人** | 被冒犯时会顶回去，而不是一味客气 |
| **群聊** | 在群里参与对话，而不是只回复 @ |
| **记忆** | 记得住前几天聊过什么 |

**方向很明确：让它更像一个活人。**

## 四、⚠️ 安全：现在有三件事必须做

验证阶段图方便，我们放松了很多。**长期跑之前，处理掉。**

### 1. 改掉所有默认密码

| 东西 | 状态 |
|---|---|
| 面板 | 首次登录已强制改密；确认现在的密码不是你随手敲的 |
| AstrBot 控制台 | 05 篇改过，确认一下 |
| SnowLuma 控制台 | 去控制台里改 |
| 远程桌面 | 去容器配置里改 |

### 2. 别把内部接口暴露到公网

| 端口 | 要不要暴露 |
|---|---|
| 6185（AstrBot 控制台） | ⚠️ 最好只对内网 / 加个反代+密码 |
| 5099（SnowLuma 控制台） | ⚠️ 同上 |
| **6199（容器通信）** | ❌ **绝对不要** |

> 这些页面都是「能执行操作」的管理后台。被扫到 = 你的号可能被拿走。

### 3. 撤销用过的 token

如果过程中你生成过 GitHub token、Gitee 令牌之类的，
**用完立刻去撤销**。它们等于钥匙。

## 五、关于风控：说点实在的

**这是非官方接口。** 意味着：

- 可能今天好好的，明天就登不上了
- 可能账号被限制
- **官方随时可能改接口，改了我们就得跟着改**

**降低风险的做法：**

1. **用小号。** 这条最重要
2. **别太勤。** 真实的人不会一天发十条动态
3. **别主动加陌生人。** 新号到处加人特别容易触发风控
4. **别用它做违规的事。** 这个不用解释
5. **IP 要干净。** 如果这个 IP 上挂过很多号，容易连坐

**做好心理准备：这东西说不定哪天就失效了。** 这是用非官方接口的代价。

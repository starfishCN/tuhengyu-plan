# 07 · 配置模型

链路正常后，给 AstrBot 配置一个模型服务商。

## 一、准备 API Key

推荐先使用能从服务器直连的国内服务商，例如 DeepSeek、通义千问或硅基流动。注册后创建 API Key，立即保存，不要发给别人。

## 二、在 AstrBot 中填写

打开 AstrBot 控制台，找到模型提供商或 Provider 设置，新增一个 OpenAI 兼容服务商。

以 DeepSeek 为例：

| 项目 | 值 |
|---|---|
| API Base | `https://api.deepseek.com/v1` |
| API Key | 你自己的 Key |
| 模型 | `deepseek-chat` |

保存并设为默认。

## 三、测试

用另一个 QQ 号给机器人发送：

```text
在吗
```

成功条件：AstrBot 日志出现收到消息和调用模型记录，SnowLuma 日志出现发送记录，QQ 收到回复。

## 没有回复

按顺序检查：

1. 两个控制台是否显示已连接。
2. Provider 是否已启用并设为默认。
3. API Key 是否有效、账户是否有余额。
4. API Base 是否包含正确的 `/v1`。
5. AstrBot 日志中的最后一条错误。
